# Ocala Fence Install — Web

Astro website for Ocala Fence Install (Marion County, FL).

## Deploy

Auto-deploys to Cloudflare Pages on every push to `main`.

- **Production:** https://ocala-fence-install.pages.dev
- **Preview:** https://preview.ocala-fence-install.pages.dev (branch `preview`)

## Local dev

```bash
npm install
npm run dev
```

Open http://localhost:4321
